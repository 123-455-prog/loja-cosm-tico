# Cosmetic Website — Front-end

Site estatico (HTML, CSS e JS puro) de uma loja de cosmeticos.

## Estrutura

```
front-end/
├── index.html
├── css/
│   ├── style.css
│   └── style.scss
├── js/
│   └── script.js
└── images/
```

## Como rodar

Pre-requisitos: [Node.js](https://nodejs.org/) e npm instalados.

1. Entre na pasta do projeto:
   ```
   cd front-end
   ```
2. Instale as dependencias:
   ```
   npm install
   ```
3. Inicie o servidor local:
   ```
   npm start
   ```

Isso vai abrir o site automaticamente no navegador em `http://localhost:3000`, com live-reload a cada alteracao nos arquivos.

## Tecnologias

- HTML5 / CSS3 / JavaScript
- Font Awesome (via CDN)
- Swiper.js (via CDN)
- LightGallery (via CDN)
